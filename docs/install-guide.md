# Jr. Lancers Basketball App
## Installation Guide

Welcome to the Jr. Lancers! This guide will help you install our team app on your phone.

---

## What is this app?

The Jr. Lancers app is a **web app** that works like a regular app on your phone. It gives you access to:
- Game schedules and locations
- Live game stats
- Team playbook
- Team chat and announcements
- Player roster and contacts
- Game highlights (photos/videos)
- Attendance and volunteer signups

---

## Installation Instructions

### iPhone / iPad

1. **Open Safari** (must use Safari, not Chrome)

2. **Go to:** `lancers-bball.web.app`

3. **Tap the Share button** (square with arrow pointing up)

```
┌─────────────────────────────────┐
│                            [ ↑ ]│  ← Tap this
│  lancers-bball.web.app          │
│                                 │
└─────────────────────────────────┘
```

4. **Scroll down and tap "Add to Home Screen"**

```
┌─────────────────────────────────┐
│  Add to Reading List            │
│  Add Bookmark                   │
│  Add to Favorites               │
│  ──────────────────────────     │
│  ☐ Add to Home Screen      ← Tap│
└─────────────────────────────────┘
```

5. **Tap "Add"** in the top right corner

6. The Jr. Lancers app icon will appear on your home screen!

---

### Android Phone

1. **Open Chrome**

2. **Go to:** `lancers-bball.web.app`

3. **Tap the three dots** (menu) in the top right corner

```
┌─────────────────────────────────┐
│                            [ ⋮ ]│  ← Tap this
│  lancers-bball.web.app          │
│                                 │
└─────────────────────────────────┘
```

4. **Tap "Add to Home screen"** or "Install app"

5. **Tap "Add"** to confirm

6. The Jr. Lancers app icon will appear on your home screen!

## First Time Setup

1. **Open the app** from your home screen

2. **Tap "Register"** to create your account

```
┌─────────────────────────────────┐
│                                 │
│      JR. LANCERS BASKETBALL     │
│                                 │
│   ┌─────────────────────────┐   │
│   │       Register          │   │  ← Tap this
│   └─────────────────────────┘   │
│                                 │
│   Already have an account?      │
│   Sign In                       │
│                                 │
└─────────────────────────────────┘
```

3. **Enter your email** (use the same email you gave Coach Logan)

4. **Create a password** (at least 6 characters)

5. **Tap Register**

6. **Check your email** for a verification link and click it

7. **Return to the app** and sign in

You'll be automatically logged in and see your child's information!

## Troubleshooting

**"Add to Home Screen" not showing?**
- iPhone: Make sure you're using Safari (not Chrome)
- Android: Make sure you're using Chrome

**Can't register?**
- Make sure you're using the email address you provided to Coach Logan
- Only pre-approved parent emails can register
- If you get an error, contact Coach Logan

**Verification email not arriving?**
- Check your spam/junk folder
- Wait a few minutes and try again
- Contact Coach Logan if still having issues

**App not loading?**
- Check your internet connection
- Try refreshing the page
- Clear your browser cache
