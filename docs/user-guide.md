# Jr. Lancers Basketball App
## User Guide

A complete guide to using all the features in the Jr. Lancers team app.

---

## Navigation

The app has 7 tabs at the bottom of every screen:

```
┌─────────────────────────────────────────────────────┐
│ Home │Roster│Sched │ Chat │Plays│Stats│Highlights│  │
│  🏠  │  👥  │  📅  │  💬  │  📋 │  📊 │    🎥    │  │
└─────────────────────────────────────────────────────┘
```

Tap any tab to navigate to that section.

### Invite Viewers

You can invite family members (grandparents, aunts, uncles) to view the app:

1. Find your child's player card
2. Tap the **"Invite Viewer"** button
3. Enter their name, email, and relationship
4. They'll receive an email invitation to create an account

*Viewers can see schedules, stats, and highlights but cannot access chat or playbook.*

## Tips for Game Day

1. **Check attendance** - Make sure you've responded
2. **Review the schedule** - Confirm time and location
3. **Check Chat** - Look for any last-minute updates from Coach
4. **Watch live stats** - Follow along if you can't be there
5. **Upload highlights** - Share great moments with the team!
